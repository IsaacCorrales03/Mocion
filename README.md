# Mocion

Mocion es una plataforma web que busca ofrecer a los jóvenes un espacio para debatir.

La idea principal es realizar debates en vivo con público, chat, votaciones y jurado.

## Tecnologías

* Go
* React
* HTML
* CSS
* JavaScript

## MVP

* Login y registro
* Video de prueba
* Crear debates
* Streaming en vivo
* Chat en vivo
* Votaciones
* Jurado
* Explorar debates en vivo
